## Теоретическая часть

### Основные конструкции для управления условиями в C#

1.  **Оператор `if` / `else if` / `else`**: Основная конструкция для ветвления логики.
    ```csharp
    if (condition1) // Если условие 1 истинно (true)
    {
        // Выполняется этот блок кода
    }
    else if (condition2) // Иначе, если условие 2 истинно
    {
        // Выполняется этот блок кода
    }
    else // Во всех остальных случаях
    {
        // Выполняется этот блок кода
    }
    ```

2.  **Тернарный условный оператор (`? :`)**:
    Краткая форма для простых условий, возвращающая одно из двух значений.
    ```csharp
    variable = (condition) ? expressionIfTrue : expressionIfFalse;
    string result = (age >= 18) ? "Взрослый" : "Не взрослый";
    ```

3.  **Оператор выбора `switch`**:
    Идеален для множественного ветвления, когда одна переменная или выражение сравнивается с множеством постоянных значений.
    ```csharp
    int day = 3;
    switch (day)
    {
        case 1:
            Console.WriteLine("Понедельник");
            break;
        case 2:
            Console.WriteLine("Вторник");
            break;
        default:
            Console.WriteLine("Другой день");
            break;
    }
    ```

4.  **Циклы** (`while`, `do-while`, `for`, `foreach`):
    Повторяют блок кода, пока выполняется условие (подробнее — в лекции 2).
    ```csharp
    // while: условие проверяется до итерации
    int counter = 3;
    while (counter > 0)
    {
        Console.WriteLine(counter--);
    }

    // do-while: тело выполнится хотя бы один раз
    int attempt = 0;
    do
    {
        attempt++;
    } while (attempt < 3);

    // for: известно количество итераций
    for (int i = 0; i < 5; i++)
    {
        Console.WriteLine(i);
    }

    // foreach: перебор элементов коллекции
    string[] fruits = ["apple", "banana"];
    foreach (string fruit in fruits)
    {
        Console.WriteLine(fruit);
    }
    ```
    Ключевые слова `break` (прервать цикл) и `continue` (перейти к следующей итерации) управляют выполнением цикла.

## Практический пример

Ниже разобран пример, которого нет среди вариантов: проверка надёжности пароля.
Он показывает, как сочетать ветвление, логические операторы и цикл.
Это учебная проверка четырёх формальных требований, а не оценка реальной стойкости пароля.

**Постановка.** Программа запрашивает пароль и проверяет четыре требования:
длина не меньше 8 символов, есть хотя бы одна цифра, есть заглавная буква,
есть один из символов `!@#$%^&*`. Невыполненные требования выводятся списком,
после чего запрос повторяется. Команда `exit` завершает программу.

**Ключевой фрагмент** — файл `Program.cs` консольного проекта .NET 10
(top-level statements: код выполняется сверху вниз):

```csharp
const string SpecialChars = "!@#$%^&*";

while (true)
{
    Console.Write("Введите пароль (или exit для выхода): ");
    string? password = Console.ReadLine();

    if (password == "exit")
    {
        Console.WriteLine("Проверка завершена.");
        break;
    }

    if (string.IsNullOrEmpty(password))
    {
        Console.WriteLine("Ошибка: пароль не может быть пустым.");
        continue;
    }

    bool hasLength = password.Length >= 8;
    bool hasDigit = password.Any(char.IsDigit);
    bool hasUpper = password.Any(char.IsUpper);
    bool hasSpecial = password.IndexOfAny(SpecialChars.ToCharArray()) >= 0;

    if (hasLength && hasDigit && hasUpper && hasSpecial)
    {
        Console.WriteLine("Пароль надёжен.");
        break;
    }

    Console.WriteLine("Пароль ненадёжен. Не выполнено:");
    if (!hasLength) Console.WriteLine("- минимум 8 символов;");
    if (!hasDigit) Console.WriteLine("- хотя бы одна цифра;");
    if (!hasUpper) Console.WriteLine("- хотя бы одна заглавная буква;");
    if (!hasSpecial)
    {
        Console.WriteLine("- хотя бы один символ из !@#$%^&*.");
    }
}
```

`Any` — метод LINQ: проверяет, есть ли хотя бы один символ, для которого условие истинно. `IndexOfAny` — метод строки: возвращает позицию любого из перечисленных символов или `-1`.

**Ожидаемый вывод** для трёх попыток:

```text
Введите пароль (или exit для выхода): qwerty
Пароль ненадёжен. Не выполнено:
- минимум 8 символов;
- хотя бы одна цифра;
- хотя бы одна заглавная буква;
- хотя бы один символ из !@#$%^&*.
Введите пароль (или exit для выхода): Qwerty12
Пароль ненадёжен. Не выполнено:
- хотя бы один символ из !@#$%^&*.
Введите пароль (или exit для выхода): Qwerty12!
Пароль надёжен.
```

**Что проверить на этом примере:**

- `qwerty` не проходит все четыре требования;
- `Qwerty12` не проходит только по спецсимволу;
- `Qwerty12!` проходит;
- пустая строка не завершает программу;
- `exit` завершает работу.

Разбор — образец уровня детализации, а не готовый ответ: в работе нужны свои
скриншоты, комментарии в коде и проверка граничных случаев (пункты 3, 4 и 6
хода работы).

## Варианты заданий

Во всех вариантах программа должна собираться без предупреждений и не завершаться при неверном вводе. Если в варианте не сказано иное, запрос повторяется до корректных данных; если полей несколько, при ошибке в одном из них повторяйте ввод с начала. Дробные числа вводятся с точкой и разбираются через `double.TryParse(..., CultureInfo.InvariantCulture)`; подключите `using System.Globalization;`.

**Сложность:** базовая — варианты 1, 2, 7, 10, 12, 13, 14; средняя — 3, 4, 6, 9, 11; повышенная — 5, 8, 15. Уровень влияет на объём работы, но шкала оценки едина для всех вариантов.

### Вариант 1. Калькулятор оценок

**Вход:** целое число от 0 до 100.
**Выход:** исходный балл и буквенная оценка: A (90–100), B (80–89), C (70–79), D (60–69), F (0–59).
**Ограничения:** нечисловой ввод, пустая строка и число вне диапазона — сообщение об ошибке и повторный запрос.

### Вариант 2. Определение времени года

**Вход:** номер месяца от 1 до 12.
**Выход:** название сезона: 12, 1, 2 — зима; 3–5 — весна; 6–8 — лето; 9–11 — осень.
**Ограничения:** число вне диапазона и нечисловой ввод — сообщение об ошибке; выбор сезона реализуйте через `switch`.

### Вариант 3. Проверка простого числа

**Вход:** целое число `n ≥ 2`.
**Выход:** «`n` — простое число» или «`n` — составное число».
**Ограничения:** числа меньше 2 — ошибка; проверяйте делители от 2 до `√n` включительно; используйте цикл.

### Вариант 4. Калькулятор с операцией

**Вход:** два числа и символ операции `+`, `-`, `*` или `/`.
**Выход:** результат с двумя знаками после запятой.
**Ограничения:** числа — дробные, разделитель — точка; нечисловой ввод, неизвестная операция и деление на ноль — сообщение об ошибке и повторный запрос.

### Вариант 5. Определение типа треугольника

**Вход:** три длины сторон — положительные числа.
**Выход:** тип треугольника: равносторонний, равнобедренный, разносторонний или «треугольник не существует».
**Ограничения:** нечисловой ввод и стороны меньше или равны нулю — сообщение об ошибке и повторный запрос; стороны считаются равными, если модуль их разности меньше `1e-6`; треугольник существует, если сумма каждых двух сторон больше третьей с тем же допуском (`a + b > c + 1e-6` и аналогично для остальных пар); если неравенство не выполняется, выведите «треугольник не существует» — это результат, а не ошибка.

### Вариант 6. Конвертер валют

**Вход:** направление конвертации (1 — из USD в EUR, 2 — из EUR в USD) и сумма больше нуля.
**Выход:** результат с двумя знаками после запятой по курсам: 1 USD = 0.90 EUR, 1 EUR = 1.10 USD.
**Ограничения:** неизвестное направление, неположительная сумма и нечисловой ввод — сообщение об ошибке; направление выбирайте через `switch`.

### Вариант 7. Определение високосного года

**Вход:** год от 1 до 9999.
**Выход:** «год високосный» или «год не високосный».
**Ограничения:** год вне диапазона — сообщение об ошибке; правило: год делится на 4 и не делится на 100 либо делится на 400.

### Вариант 8. Игра «Угадай число»

**Вход:** целое число от 1 до 10 — очередная попытка угадать загаданное число 7.
**Выход:** подсказка «Больше», если введённое число меньше загаданного, и «Меньше», если больше; после победы — «Победа!» и число попыток.
**Ограничения:** неверный ввод не считается попыткой; после 5 неудачных попыток выведите «Попытки закончились» и загаданное число.

### Вариант 9. Проверка логина и пароля

**Вход:** логин и пароль.
**Выход:** «Доступ разрешён» для пары `admin` / `password`, иначе «Неверный логин или пароль».
**Ограничения:** пустые строки — сообщение об ошибке, попытка не расходуется; сравнение точное, регистр учитывается, пробелы по краям не удаляются; после трёх неудачных попыток — «Доступ заблокирован».

### Вариант 10. Определение дня недели

**Вход:** номер дня недели от 1 до 7.
**Выход:** название дня недели.
**Ограничения:** число вне диапазона — сообщение об ошибке; реализуйте решение двумя способами — через `if-else if` и через `switch`; выведите оба результата подряд, они должны совпадать, сравнение подходов опишите в комментариях.

### Вариант 11. Подсчёт стоимости разговора

**Вход:** код страны (1 — США, 49 — Германия, 86 — Китай) и длительность разговора больше нуля минут.
**Выход:** стоимость до и после скидки с двумя знаками после запятой: США — 5 руб./мин, Германия — 7 руб./мин, Китай — 3 руб./мин; при длительности больше 10 минут скидка 10 %.
**Ограничения:** неизвестный код страны, неположительная длительность и нечисловой ввод — сообщение об ошибке.

### Вариант 12. Классификация возраста

**Вход:** возраст от 0 до 120 лет.
**Выход:** категория и описание: 0–1 — младенец, 2–12 — ребёнок, 13–19 — подросток, 20–64 — взрослый, 65–120 — пенсионер.
**Ограничения:** возраст вне диапазона — сообщение об ошибке; проверьте границы 1/2, 12/13, 19/20 и 64/65.

### Вариант 13. Калькулятор ИМТ

**Вход:** рост от 0.5 до 2.5 м и вес от 1 до 300 кг (границы включительно).
**Выход:** ИМТ, округлённый до одного знака, и категория: меньше 18.5 — недостаточный вес, 18.5–24.9 — норма, 25.0–29.9 — избыточный вес, 30.0 и больше — ожирение.
**Ограничения:** неверный ввод — сообщение об ошибке; ИМТ = вес / рост²; округление `Math.Round(bmi, 1, MidpointRounding.AwayFromZero)`, классификация по округлённому значению.

### Вариант 14. Проверка строки

**Вход:** строка.
**Выход:** три результата: пустая ли строка; является ли она целым числом; длиннее ли она 5 символов — последнее сообщение через тернарный оператор.
**Ограничения:** строка из пробелов считается пустой; число проверяйте через `int.TryParse`; любая строка допустима, повторный запрос не требуется.

### Вариант 15. Машина состояний «Светофор»

**Вход:** команды `next` — следующий сигнал и `stop` — выход.
**Выход:** текущий сигнал: красный → жёлтый → зелёный → красный.
**Ограничения:** при запуске сразу выведите «Красный»; `next` переключает на следующий сигнал, `stop` завершает; неизвестная команда — сообщение об ошибке; работать без задержек, чтобы вывод был воспроизводимым.
