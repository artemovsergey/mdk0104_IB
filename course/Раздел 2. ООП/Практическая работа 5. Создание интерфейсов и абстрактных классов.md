# Практическая работа 5. Создание интерфейсов и абстрактных классов

**Тема:** Реализация принципов ООП в C#: интерфейсы и абстрактные классы.

**Цель:** Сформировать практические навыки проектирования и реализации иерархий классов с использованием интерфейсов и абстрактных классов для создания гибких, расширяемых и сопровождаемых приложений.

**Задачи:**
1.  Научиться декларировать интерфейсы и абстрактные классы.
2.  Освоить механизмы наследования от абстрактных классов и реализации интерфейсов.
3.  Понять разницу между абстрактными методами и методами по умолчанию в интерфейсах.
4.  Закрепить принцип полиморфизма при работе с объектами через ссылки на базовые классы и интерфейсы.
5.  Научиться применять полученные знания для моделирования предметных областей.

**Ход работы:**
1.  Ознакомиться с теоретическим материалом.
2.  Получить вариант задания у преподавателя.
3.  Создать новое консольное приложение .NET с именем `PracticalWork_5`.
4.  Реализовать требуемую иерархию классов и интерфейсов согласно варианту.
5.  В методе `Main` создать коллекцию (например, `List<T>`) объектов различных конкретных классов, но приведенных к базовому типу (интерфейсу или абстрактному классу).
6.  Продемонстрировать работу всех методов, включая унаследованные, переопределенные и реализованные, в цикле или отдельными вызовами.
7.  Оформить отчёт в файле `README.md` своего репозитория.
8.  Загрузить проект в удаленный репозиторий (GitHub, GitLab, etc.) и предоставить ссылку преподавателю.

**Критерии оценки:**

## Решение

### Код проекта

#### Абстрактный класс Shape и интерфейс IDrawable
```csharp
public abstract class Shape
{
    public abstract double CalculateArea();
    public abstract double CalculatePerimeter();
}

public interface IDrawable
{
    void Draw();
}
```

#### Класс Circle
```csharp
public class Circle : Shape, IDrawable
{
    public double Radius { get; set; }

    public Circle(double radius)
    {
        Radius = radius;
    }

    public override double CalculateArea()
    {
        return Math.PI * Radius * Radius;
    }

    public override double CalculatePerimeter()
    {
        return 2 * Math.PI * Radius;
    }

    public void Draw()
    {
        Console.WriteLine($"Рисую круг с радиусом {Radius}.");
    }
}
```

#### Класс Rectangle
```csharp
public class Rectangle : Shape, IDrawable
{
    public double Width { get; set; }
    public double Height { get; set; }

    public Rectangle(double width, double height)
    {
        Width = width;
        Height = height;
    }

    public override double CalculateArea()
    {
        return Width * Height;
    }

    public override double CalculatePerimeter()
    {
        return 2 * (Width + Height);
    }

    public void Draw()
    {
        Console.WriteLine($"Рисую прямоугольник {Width}x{Height}.");
    }
}
```

#### Главный метод Program.cs
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main(string[] args)
    {
        // Создаем коллекцию фигур, работая через базовые типы
        List<Shape> shapes = new List<Shape>
        {
            new Circle(5.0),
            new Rectangle(4.0, 6.0)
        };

        // Демонстрация полиморфизма: вычисление площадей и периметров
        Console.WriteLine("=== Вычисление площадей и периметров ===");
        foreach (var shape in shapes)
        {
            Console.WriteLine($"Площадь: {shape.CalculateArea():F2}");
            Console.WriteLine($"Периметр: {shape.CalculatePerimeter():F2}");
            Console.WriteLine();
        }

        // Демонстрация работы через интерфейс IDrawable
        Console.WriteLine("=== Отрисовка фигур ===");
        List<IDrawable> drawables = new List<IDrawable>
        {
            new Circle(5.0),
            new Rectangle(4.0, 6.0)
        };

        foreach (var drawable in drawables)
        {
            drawable.Draw();
        }
    }
}
```
