# Лекция 5. Entity Framework Core (EF Core). ORM для C#

### Цель лекции

Познакомить студентов с ORM (Object-Relational Mapping) в C#, на примере Entity Framework Core, показать, как работать с базой данных через объекты C# без написания SQL-запросов вручную.

---

## **1. Что такое ORM**

* **ORM (Object-Relational Mapping)** — это технология, которая позволяет работать с базой данных через объекты языка программирования.
* Цель — избавиться от ручного написания SQL-запросов, облегчить поддержку кода.
* Пример: объект `Student` в C# соответствует таблице `Students` в базе данных.

---

## **2. Entity Framework Core (EF Core)**

* Современная ORM от Microsoft для современного .NET (актуальная версия — EF Core 10 на .NET 10).
* Поддерживает различные базы данных: SQL Server, SQLite, PostgreSQL, MySQL.
* Основные возможности:

  * Создание моделей (классов) и контекста базы данных
  * CRUD операции (Create, Read, Update, Delete)
  * LINQ-запросы к базе данных
  * Асинхронные операции (async/await) — запросы не блокируют поток
  * Миграции (обновление структуры базы данных)

---

## **3. Основные компоненты EF Core**

1. **Entity (Сущность)**

   * Класс C#, который соответствует таблице в базе данных.

   ```csharp
   public class Student
   {
       public int Id { get; set; }

       // required требует задать значение при создании объекта (C# 11+)
       public required string Name { get; set; }

       public int Age { get; set; }
   }
   ```

   > Установка провайдера PostgreSQL для EF Core: `dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL`

2. **DbContext (Контекст базы данных)**

   * Основной класс для работы с EF Core.
   * Представляет сессию с базой данных.

   ```csharp
   using Microsoft.EntityFrameworkCore;

   public class SchoolContext : DbContext
   {
       public DbSet<Student> Students { get; set; }

       protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
       {
           // Пример строки подключения к PostgreSQL.
           // В кабинете используйте строку подключения, выданную преподавателем.
           optionsBuilder.UseNpgsql(
               "Host=localhost;Port=5432;Database=mdk0104_ib;Username=postgres;Password=postgres"
           );
       }
   }
   ```

3. **DbSet**

   * Представляет коллекцию объектов, соответствующих таблице.
   * Позволяет выполнять запросы, добавлять и удалять записи.

---

## **4. Основные операции**

Все примеры выполняются в `Program.cs` с top-level statements, поэтому доступен `await`. Запросы к базе данных выполняются асинхронно (`ToListAsync`, `SaveChangesAsync` и т.д.), а для чтения используется `AsNoTracking()` — он отключает отслеживание изменений и ускоряет запросы.

1. **Добавление записи**

```csharp
await using var context = new SchoolContext();

Student student = new() { Name = "Alice", Age = 20 };
context.Students.Add(student);
await context.SaveChangesAsync();
```

2. **Чтение данных**

```csharp
await using var context = new SchoolContext();

List<Student> students = await context.Students.AsNoTracking().ToListAsync();
foreach (Student s in students)
{
    Console.WriteLine($"{s.Id}: {s.Name}, {s.Age}");
}
```

3. **Обновление данных**

```csharp
await using var context = new SchoolContext();

Student? student = await context.Students.FirstOrDefaultAsync();
if (student is not null)
{
    student.Age = 21;
    await context.SaveChangesAsync();
}
```

4. **Удаление записи**

```csharp
await using var context = new SchoolContext();

Student? student = await context.Students.FirstOrDefaultAsync();
if (student is not null)
{
    context.Students.Remove(student);
    await context.SaveChangesAsync();
}
```

---

## **5. LINQ-запросы с EF Core**

* Используем стандартные LINQ-операторы для фильтрации, сортировки и проекции данных:

```csharp
await using var context = new SchoolContext();

List<Student> adults = await context.Students
    .AsNoTracking()
    .Where(s => s.Age >= 18)
    .OrderBy(s => s.Name)
    .ToListAsync();
```

* Можно использовать методы `FirstOrDefault`, `SingleOrDefault`, `Any`, `Count` — у каждого есть асинхронная версия для запросов к базе: `FirstOrDefaultAsync`, `AnyAsync`, `CountAsync` и т.д.

---

## **6. Миграции**

* EF Core позволяет обновлять структуру базы данных без ручного SQL.
* Работа с миграциями выполняется через **.NET CLI** (Package Manager Console из Visual Studio в курсе не используется).
* Установка инструмента `dotnet ef` (один раз на компьютере) и пакета для проекта:

  ```bash
  dotnet tool install --global dotnet-ef
  dotnet add package Microsoft.EntityFrameworkCore.Design
  ```

* Команды выполняются в терминале в папке проекта:

  ```bash
  dotnet ef migrations add InitialCreate
  dotnet ef database update
  ```

  * `dotnet ef migrations add InitialCreate` — создать миграцию
  * `dotnet ef database update` — применить миграцию к базе данных

---

## **7. Преимущества EF Core**

* Ускоряет разработку, меньше ручного кода.
* Позволяет работать с базой данных через привычные объекты C#.
* Поддерживает разные типы баз данных.
* Интеграция с ASP.NET Core и другими проектами .NET.

---

## **8. Недостатки EF Core**

* Возможна потеря производительности при сложных запросах.
* Не всегда можно контролировать SQL, который генерируется.
* Для сложных сценариев иногда требуется использовать чистый SQL (`FromSqlRaw`).

## **9. Пример полного кода EF Core**

**Файл Student.cs:**

```csharp
public class Student
{
    public int Id { get; set; }
    public required string Name { get; set; }
    public int Age { get; set; }
}
```

**Файл SchoolContext.cs:**

```csharp
using Microsoft.EntityFrameworkCore;

public class SchoolContext : DbContext
{
    public DbSet<Student> Students { get; set; }

    protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
    {
        // В кабинете используйте строку подключения, выданную преподавателем
        optionsBuilder.UseNpgsql(
            "Host=localhost;Port=5432;Database=mdk0104_ib;Username=postgres;Password=postgres"
        );
    }
}
```

**Файл Program.cs (top-level statements):**

```csharp
await using var context = new SchoolContext();

// Применяем миграции (создаются командами dotnet ef migrations add / dotnet ef database update).
// EnsureCreated() использовать не нужно: миграции удобнее и не теряют данные при изменении модели.
await context.Database.MigrateAsync();

// Добавление
context.Students.Add(new Student { Name = "Alice", Age = 20 });
context.Students.Add(new Student { Name = "Bob", Age = 22 });
await context.SaveChangesAsync();

// Чтение
List<Student> students = await context.Students.AsNoTracking().ToListAsync();
foreach (Student s in students)
{
    Console.WriteLine($"{s.Id}: {s.Name}, {s.Age}");
}

// Обновление
Student? firstStudent = await context.Students.FirstOrDefaultAsync();
if (firstStudent is not null)
{
    firstStudent.Age = 21;
    await context.SaveChangesAsync();
}

// Удаление
Student? lastStudent = await context.Students
    .OrderByDescending(s => s.Id)
    .FirstOrDefaultAsync();
if (lastStudent is not null)
{
    context.Students.Remove(lastStudent);
    await context.SaveChangesAsync();
}
```
