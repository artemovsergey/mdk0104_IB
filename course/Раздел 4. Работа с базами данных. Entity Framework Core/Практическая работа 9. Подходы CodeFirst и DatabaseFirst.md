# Практическая работа 9. Подходы Code-First и Database-First

### Цель работы

Научиться использовать два подхода работы с базой данных в Entity Framework Core: **Code-First** и **Database-First**. Освоить создание моделей, контекста и генерацию базы данных, а также обратное создание моделей из существующей базы данных.

---

## **Теоретическая часть**

### **1. Подход Code-First**

* **Суть:** сначала создаются классы C# (модели), потом EF Core генерирует базу данных.
* **Преимущества:**

  * Полный контроль над моделями через код
  * Легко управлять версионированием через миграции
* **Недостатки:**

  * Требует знания EF Core и конфигурации моделей
* **Этапы работы:**

  1. Создать классы-сущности
  2. Создать DbContext
  3. Настроить подключение к базе данных
  4. Создать миграцию и применить её (`dotnet ef migrations add InitialCreate`, `dotnet ef database update`)

**Пример модели и контекста:**

```csharp
using Microsoft.EntityFrameworkCore;

public class Student
{
    public int Id { get; set; }
    public required string Name { get; set; }
    public int Age { get; set; }
}

public class SchoolContext : DbContext
{
    public DbSet<Student> Students { get; set; }

    protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
    {
        // В кабинете используйте строку подключения, выданную преподавателем
        optionsBuilder.UseNpgsql(
            "Host=localhost;Port=5432;Database=mdk0104_ib;Username=postgres;Password=postgres"
        );
    }
}
```

### **2. Подход Database-First**

* **Суть:** база данных создаётся заранее, а модели и контекст генерируются из неё.
* **Преимущества:**

  * Можно работать с уже существующей базой данных
  * Быстро получить C# модели без ручного описания
* **Недостатки:**

  * Меньший контроль над структурами
  * Обновление модели при изменении БД требует повторной генерации
* **Этапы работы:**

  1. Создать базу данных и таблицы (например, в PostgreSQL через pgAdmin или SQL-скрипт)
  2. Сгенерировать модели и контекст командой `dotnet ef dbcontext scaffold`:

     ```bash
     dotnet ef dbcontext scaffold "Host=localhost;Port=5432;Database=school_db;Username=postgres;Password=postgres" Npgsql.EntityFrameworkCore.PostgreSQL -o Models
     ```

## **Ход работы**

### **1. Code-First**

1. Создать консольное приложение: `dotnet new console -n CodeFirstDemo`
2. Установить пакеты:

   ```bash
   dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL
   dotnet add package Microsoft.EntityFrameworkCore.Design
   ```

3. Создать классы-сущности `Student`, `Course`, `Enrollment`.
4. Создать контекст `SchoolContext` и настроить подключение к PostgreSQL.
5. Создать и применить миграцию:

   ```bash
   dotnet ef migrations add InitialCreate
   dotnet ef database update
   ```

6. Добавить, прочитать и удалить записи через DbContext.

### **2. Database-First**

1. Создать в PostgreSQL базу данных с таблицей `students` (pgAdmin или SQL-скрипт):

   ```sql
   CREATE TABLE students (
       id SERIAL PRIMARY KEY,
       name VARCHAR(50) NOT NULL,
       age INT NOT NULL
   );
   ```

2. Сгенерировать модели и DbContext командой `dotnet ef dbcontext scaffold` (пример — в теоретической части).
3. Создать консольное приложение `DatabaseFirstDemo`.
4. Использовать сгенерированный DbContext для выполнения CRUD-операций.

### **3. Оформление отчёта**

1. Сделать скриншоты работы обеих программ и поместить их в папку `images`.
2. Создать `readme.md` по образцу ниже.
3. Инициализировать git-репозиторий и отправить проект на Gogs:

   ```bash

   git commit -m "Практическая работа 9"
   ```

## **Пример кода (Code-First)**

**Файл Student.cs:**

```csharp
public class Student
{
    public int Id { get; set; }
    public required string Name { get; set; }
    public int Age { get; set; }
}
```

**Файл SchoolContext.cs:**

```csharp
using Microsoft.EntityFrameworkCore;

public class SchoolContext : DbContext
{
    public DbSet<Student> Students { get; set; }

    protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
    {
        // В кабинете используйте строку подключения, выданную преподавателем
        optionsBuilder.UseNpgsql(
            "Host=localhost;Port=5432;Database=mdk0104_ib;Username=postgres;Password=postgres"
        );
    }
}
```

**Файл Program.cs (top-level statements):**

```csharp
await using var context = new SchoolContext();

// Миграции создаются командами dotnet ef migrations add / dotnet ef database update
await context.Database.MigrateAsync();

context.Students.Add(new Student { Name = "Alice", Age = 20 });
context.Students.Add(new Student { Name = "Bob", Age = 22 });
await context.SaveChangesAsync();

List<Student> students = await context.Students.AsNoTracking().ToListAsync();
foreach (Student s in students)
{
    Console.WriteLine($"{s.Id}: {s.Name}, {s.Age}");
}
```
